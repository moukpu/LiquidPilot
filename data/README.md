# Data

This directory contains synthetic data generators and historical fixtures for LiquidPilot.

## Approach

Since this is a hackathon project, we use **synthetic data** to simulate:

- Multi-currency treasury accounts
- Inter-bank transactions
- Historical crisis scenarios (2008, 2020, 2023)
- Bank exposure networks for contagion analysis

Generators live in `generators/`. Historical crisis datasets live in `fixtures/`.

All data is anonymized and purely for demonstration purposes.
